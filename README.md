\# GitHub Trending CLI



A command-line tool that uses the GitHub API to display trending repositories.



\## Features



\- Filter by day, week, month, or year

\- Set the number of repositories with `--limit`

\- Sort repositories by stars

\- Display repository name, description, stars, and language

\- GitHub API error handling

\- No authentication required



\## Run



python trending\_repos.py --duration week --limit 10



\## Examples



python trending\_repos.py --duration day --limit 5



python trending\_repos.py --duration month --limit 20



python trending\_repos.py --duration year --limit 10
